OCUDUAgentBench Technical Details

This document is the implementation reference for the executable benchmark under benchmark/. It explains task loading, generated variants, episode flow, simulated runtime effects, scoring, trace partitions, and remote sync boundaries.

Documentation boundary. The repo-root benchmark/README.md is the short entry point: what the harness is, what command to run, and where the task sets live. This file is the technical reference for maintainers changing the benchmark internals. Design authority remains in skillful-ran-research/benchmark_design/.

Task Contract

Every task is loaded as a private manifest shaped around T = <G, E, U, I, J>, plus private metadata M.

FieldOwnerVisibilityMeaning
Gtask manifestagent-visible after redactionGoal text shown to the agent.
Eruntime setupbenchmark-privateRuntime adapter and requirements. Current runnable tasks use simulated_ocudu.
Ustimulusbenchmark-privateDeterministic step-targeted runtime dynamics.
IAPI projectionpartly visibleAllowed action APIs, observation sources, feedback shape, and observation detail mode.
Jscoringbenchmark-private during runRaw metrics, temporal expectations, payload expectations, and post-action evidence checks.
Mcatalog/generatorbenchmark-privateTask set, family, role, and generated-variant metadata. Never serialized to agent observations or feedback.

Task Sets

base25 tasks

Primary checked-in task set, grouped by family under benchmark/task_sets/base/<family>/.

regression1 task

Harness regression surface. It is runnable but not a primary agent-benefit benchmark family.

compound8 tasks

Checked-in latent-cause diagnosis tasks. The agent sees symptoms over time, not cause labels.

generated, standard, diagnostic, stressin memory

Single-anchor generated variants from axis_registry.json and suite_policies.json.

Generated tasks are deterministic for the same suite, seed, count, and family filter. The generator model is:

anchor task + variant axis/vector + suite seed = concrete in-memory PrivateTask

Generated Variants

Generated variants scale coverage without committing hundreds of task directories. They tune one anchor family at a time so failures stay interpretable.

InputPurpose
axis_registry.jsonDefines anchor task, family, axis name, levels or sampler transform, expected failure modes, and manifest overrides.
suite_policies.jsonDefines default counts and balancing policy for generated suites.
--seedControls deterministic variant selection and opaque generated IDs.
--countControls generated suite size. If omitted, the suite policy default is used.
--familyRestricts generation to axes with the requested public family.

Generated public IDs use the form generated_sNNNN_hash_v1. Axis names, anchor task IDs, sampled values, expected failure modes, and registry/policy checksums stay in private M.variant and run provenance, not in observations or feedback.

Episode Lifecycle

One episode is owned by episode.py. Scoring is deliberately post-run: the agent never sees scores during the interaction.

  1. Load one PrivateTask through task_catalog.py.
  2. Build the redacted agent-visible task view.
  3. Instantiate the runtime handle from E.
  4. Expand the deterministic stimulus plan from U and the episode seed.
  5. Run readiness checks before the scored interaction.
  6. For each step, apply pre-observation stimulus, emit observation, run in-step stimulus, accept an agent decision, dispatch action if needed, and record feedback.
  7. Finalize artifact manifest, cleanup runtime, finalize trace, then score the finalized trace.

Simulated OCUDU Runtime

simulated_ocudu is an executable benchmark adapter, not live OCUDU/FlexRIC. It makes local and remote simulation runs closed-loop by applying deterministic state transitions after accepted actions.

Action familySimulated effectRepresentative rejection
PRB policyUpdates slice_runtime.current_prb_policy and later slice evidence.Wrong active slice identifiers, unavailable E2/KPM, duplicate repaired policy.
SSB powerUpdates radio_runtime.current_ssb_block_power_dbm.Stale or wrong cell identity, duplicate repaired power.
HO/CHOUpdates UE serving PCI or conditional handover plan.Wrong RNTI, wrong serving PCI, target outside candidate set.
CFO/TX offsetUpdates radio impairment state and correction flags.Wrong sector or duplicate correction.
Core NF restartUpdates NF status, restart counts, and degradation state.Unavailable NF or repeated restart after recovery.
Core UE registrationUpdates visible registration status to the desired profile.Payload does not match desired visible profile.

Observation And Privacy Boundary

The agent-visible path is intentionally smaller than the private benchmark trace.

PartitionContentsAgent-visible?
interactionObservations, public action records, and redacted feedback.Yes, during or after the run depending on consumer.
private_benchmarkStimulus records, readiness checks, seeds, and benchmark-private event details.No.
oracleCleanup and scorer-only records.No.
artifact_manifestPrivate artifact location, checksum, producer, and retention class.Summary only after finalization.
run_metadata.task_provenanceTask definition digest, suite seed/count, source path, and generated registry/policy checksums.No during interaction; copied to scored summaries for replay.

I.observation_detail = diagnosis_symptoms hides direct repair targets for diagnosis tasks and exposes symptoms such as SINR, CQI, RSRP, RSRQ, queue pressure, utilization, backhaul delay/loss, and redacted core state.

Scoring

Scoring is implemented in scoring.py and requires finalized artifacts plus finalized trace. Raw metrics are authoritative; component scores are explanatory rollups.

LayerDefinition
raw_metricsTask-selected checks from J.raw_metrics, normalized to [0.0, 1.0]. Critical metrics determine pass/fail.
critical_metricsSubset of raw metrics that must meet J.success_threshold. If omitted, all requested raw metrics are critical.
component_scoresAverages for task correctness, action correctness, evidence use, RAN health, safety, and cleanup. These explain performance but do not override critical raw metrics.
efficiencyDecision latency, control round-trip, and token telemetry. These do not affect correctness.
outcomesuccess only when every critical raw metric reaches the threshold; otherwise a scored failure receives a safe failure category.

Remote Workflow Boundary

remote sync copies the local benchmark/ tree to <remote.workspace>/synced/benchmark/. It is an implementation utility for running the same simulated benchmark on the configured remote workstation. It does not make the run a live OCUDU/FlexRIC benchmark. Live-runtime claims require a separate live adapter with readiness, dispatch, artifact, cleanup, and oracle support.
